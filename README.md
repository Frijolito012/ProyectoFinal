# ProyectoFinal  
El proyecto presentado está en base al problema del pollo en la actualidad, presentando una calculadora  
con grafica incluida para mostrar la estadistica de especulacion de subida del precio del pollo en base a  
un precio de antes de todo el problema actual, un precio en la actualidad y los meses considerando que la  
situacion sigue igual
